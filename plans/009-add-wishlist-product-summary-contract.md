## Target contract

For `GET /api/v1/wishlists/me`, each returned visible row retains exactly the backward-compatible wishlist fields `id`, `userId`, `productId`, and `createdAt`, then embeds a required, non-null `product` summary for that same `productId` with exactly: `id`, localized `slug`, localized `name`, localized `description`, `categoryId`, `originalSlug`, localized `shortDescription`, `status`, `image`, `thumbnail`, localized `categoryName`, `categorySlug`, base `price`, and effective `pricing`. This is the transport shape required by FE-007's existing `mapBackendProduct`; it deliberately excludes SEO, material, care, full `images`, and `colorImages`.

The controller injects `CatalogLocaleResolver` and accepts optional `locale` plus optional `Accept-Language`; it calls `localeResolver.resolve(locale, acceptLanguage)`, so precedence is query `locale` → header → configured default → hard fallback `vi`, then passes the resolved code to the dedicated `WishlistService.getMyWishlists(email, localeCode, pageable)` method.

For each localized product/category field, lookup is requested translation → `CatalogLocaleResolver.DEFAULT_LOCALE` (`vi`) translation → base entity field; a missing field does not null out the whole summary. Representative pricing selects the variant with the minimum `VariantPricing.effectivePrice`, breaks equal-price ties by ascending `variantId`, exposes that representative variant's `listPrice` as `price`, and exposes its effective/sale result as `pricing`.

The self page contains only wishlist rows whose joined product is `ACTIVE` and `deletedAt IS NULL`. The paginated database query itself applies that predicate, so `result`, `totalElements`, and `totalPages` describe the same visible set. An absent joined product is likewise excluded by the inner join. Do not return a null/partial product summary, fail the whole page, or delete the stored wishlist row; an inactive product's wishlist row may reappear if the product becomes active again. The generic admin `/wishlists` contract remains unchanged.
